构造规范

  • 画布 24×24，内容区 20×20（外留 2px 呼吸边）。
  • 描边 1.75，圆头圆角；实心点只用于「…」类标记，半径 1.15。
  • 单色，stroke="currentColor"；放在色块上时用白（浅色）或近黑（深色）。
  • 阶段间轮廓刻意拉开：气泡 / 放大镜 / 尖括号 / 加减方块 / 烧瓶 / 圆点环。「写代码」与「改代码」是最易混的一对，所以前者是开放的 </>，后者是封闭的 ± 方块。
  • 图标不单独承载含义：始终配文字标签或 tooltip（无障碍），颜色与图案仍保留。
