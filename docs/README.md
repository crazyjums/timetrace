# docs 说明

| 路径 | 内容 |
| --- | --- |
| BRIEF.md | 产品简报（先读） |
| PRD.md | 完整产品需求文档（需自行导出，见下） |
| prototype-canvas/ | 最新界面原型源码（.dc.html，5 页）和画布布局 canvas.json |
| prototype-v0/ | 早期静态原型、色板 tokens.css、图标、概览截图 |

## PRD.md 怎么来
在文档页用「导出 → Markdown」，保存为 `docs/PRD.md`。

## 关于 prototype-canvas
.dc.html 是设计画布的源格式，依赖画布运行时（support.js），不能直接双击打开。把它当作布局、文案和数据结构的参考来读；要看渲染效果，打开画布链接。
